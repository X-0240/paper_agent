# Phase 0 报告（2026-09-16）

## 一、目标

在冻结现有 50 篇语料的前提下，验证三件事：

1. 现有 88 题基线是否被反向出题泄露虚高
2. 多通道融合/章节聚合/多 query 能否提升证据级 HitRate@5
3. LLM 重排能否救回排序失败的题

## 二、泄露 A/B

同一批论文、同一索引、同一检索器（hybrid, query=原始中文）：

| 出题方式 | 证据级@5 | 样本 |
|---|---:|---:|
| 正向出题（读整篇论文） | 64.3% | 27/42 |
| 反向出题（从 chunk 出题） | 73.8% | 31/42 |

泄露 gap = +9.5pp，低于 10pp 阈值，暂不触发返工；但属于边界值，test 集必须用正向出题。

## 三、检索模式对照（88 题 dev，原生英文 query）

| 模式 | 证据级@5 | 相对 hybrid |
|---|---:|---:|
| vector | 53.4% | -11.4pp |
| bm25 | 54.5% | -10.2pp |
| hybrid（当前基线） | 64.8% | 0 |
| rrf | 61.4% | -3.4pp |
| section 聚合 | 58.0% | -6.8pp |
| multi-query | 58.0% | -6.8pp |

结论：当前瓶颈不是融合方式，RRF/章节聚合/多 query 的简单实现都是负优化。

## 五、LLM 重排（只处理基线失败的 31 题）

| 方案 | 救回 | 累计证据级@5 |
|---|---:|---:|
| hybrid 基线 | - | 64.8%（57/88） |
| top20 LLM 重排 | 3/31 | 68.2%（60/88，+3.4pp） |
| top20 外扩池 50 LLM 重排 | 2/13 | 70.5%（62/88，+5.7pp） |

正向题集复验：

| 方案 | 证据级@5 |
|---|---:|
| hybrid 基线 | 64.3%（27/42） |
| top20 LLM 重排 | 69.0%（29/42） |
| 扩池 50 LLM 重排 | 71.4%（30/42，+7.1pp） |

## 六、Phase 0 门槛判定

| 门槛 | 结果 | 判定 |
|---|---|---|
| 88 题同集 A/B Δ≥5-7pp | +5.7pp | 通过（下沿） |
| 正向题集绝对底线 ≥65% | 71.4% | 通过 |
| 泄露 gap ≤10pp | +9.5pp | 通过（边界） |

Phase 0 通过，但绝对指标约 70.5%-71.4%，离 80% 还差约 9-10pp。

## 七、下一步

1. 数据层：表格/图注/公式结构化切片 + parent-child，目标修复 5 题 top100 外和部分 21-100 名的证据断裂
2. 证据选择：把 LLM 重排做成“低分差才触发”的按需重排，控制成本和延迟
3. 评测：正向题集扩到 50 dev / 150 test（Phase 1），并按论文分组冻结
4. 语料：扩到 150 篇冻结快照（Phase 1），每周自动更新放到 Phase 4
